XSS Capture The Flag

Een zelfgebouwde CTF-challenge die eruitzag als een YouTube-commentaarsectie. Ontworpen om Cross-Site Scripting (XSS) kwetsbaarheden te demonstreren in een herkenbare omgeving.

Rol
Solo project
Periode
Jaar 1 — 2024
Stack
Flask · MySQL · Docker

Hoe het werkt

De challenge

De deelnemer ziet een pagina die eruitziet als een YouTube-commentaarsectie. Het doel: vind en exploiteer de XSS-kwetsbaarheid om de flag te bemachtigen.

1

De omgeving verkennen

De deelnemer opent de pagina en ziet een YouTube-achtige commentaarsectie waar je reacties kunt plaatsen.

2

XSS payload injecteren

Door een script tag in het commentaarveld te plaatsen wordt duidelijk dat de input niet gesanitiseerd wordt — de kwetsbaarheid is gevonden.

3

Flag capturen

Een succesvolle XSS-aanval stuurt de deelnemer door naar een andere pagina waar de flag wordt getoond.

Concepten

Wat dit project demonstreert

Dit project combineert offensieve security kennis met webdevelopment.

🛡️

XSS kwetsbaarheden

🎯

CTF ontwerp

Een realistische, herkenbare omgeving creëren die deelnemers uitdaagt om kwetsbaarheden te vinden zonder dat het te makkelijk of te moeilijk is.

Webdevelopment
