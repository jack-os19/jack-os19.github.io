Secret Manager

Een webapplicatie waarmee gebruikers persoonlijke geheimen veilig kunnen opslaan — recepten, wachtwoorden, notities. Met een volledige registratie- en inlogflow zodat alleen jij bij jouw data kunt.

Rol
Solo project
Periode
Jaar 1 — 2024
Stack
Flask · MySQL · Docker

Functionaliteiten

Wat ik heb gebouwd

Volledig zelfstandig gebouwd als één van mijn eerste complete webapplicaties.

🔐

Authenticatie

Volledige registratie en login met gebruikersbeheer. Elke gebruiker heeft alleen toegang tot eigen geheimen.

📝

CRUD operaties

Geheimen aanmaken, bekijken, bewerken en verwijderen. Opgeslagen in een MySQL database.

🐳

Docker

Applicatie gecontaineriseerd met Docker voor consistente deployment en eenvoudig opzetten van de ontwikkelomgeving.

🎨

Frontend

Interface gebouwd met HTML en CSS. Functioneel en gebruiksvriendelijk ontwerp.
